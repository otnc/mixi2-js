## 前提条件

- **Node.js 20.19.0 以上**
- [mixi2 Developer Platform](https://developer.mixi.social) で開発者登録が完了していること
- アプリケーションを作成し、認証情報（Client ID / Client Secret / Token URL 等）を取得済みであること

## 対応環境

mixi2-js は以下のランタイム API に依存しているため、環境によって使える機能が異なります。

- [`node:http2`](https://nodejs.org/api/http2.html) (`@grpc/grpc-js` 経由): API クライアントと gRPC ストリーミング
- `node:fs` (`@grpc/proto-loader` 経由): 実行時の `.proto` の読み込み (API クライアント、gRPC ストリーミング、Webhook のデコード)
- [`node:http`](https://nodejs.org/api/http.html) と [`node:crypto`](https://nodejs.org/api/crypto.html) (Ed25519): Webhook サーバーと署名検証
- `fetch` と `Buffer`: 認証とメディアアップロード

| 環境               | 認証 (`OAuth2Authenticator`) | API クライアント (`Client`) | Webhook (`WebhookServer`) | gRPC ストリーミング (`StreamWatcher`) |
| ------------------ | ---------------------------- | --------------------------- | ------------------------- | ------------------------------------- |
| Node.js            | ✅                           | ✅                          | ✅                        | ✅                                    |
| Bun                | ✅                           | ⚠️                          | ✅                        | ⚠️                                    |
| Deno               | ⚠️                           | ⚠️                          | ⚠️                        | ⚠️                                    |
| Cloudflare Workers | ⚠️                           | ❌                          | ❌                        | ❌                                    |

✅ 動作確認済み、⚠️ 未検証または制限あり、❌ 非対応

- **Node.js**: 20.19.0 以降。CI で 20.19.0 / 22 / 24 のテストを実行しています
- **Bun**: 1.4.3 で認証と Webhook (署名検証を含む) の動作を確認済み。API クライアントと gRPC ストリーミングは生成と proto の読み込みまで確認済みで、実際の通信は未検証です
- **Deno**: 未検証です。`npm:mixi2-js` または JSR 版を Node.js 互換レイヤーで動かすことになります
- **Cloudflare Workers**: 非対応です。gRPC (`node:http2`)、`node:http` のサーバー、実行時のファイル読み込みが使えないためです。認証は `nodejs_compat` を有効にすれば動く見込みですが未検証です

:::tip
サーバーレス環境ではランタイムが対応していても gRPC ストリーミングを常時接続できない場合があります。環境に合わせて [Webhook](/guides/webhook/) と [gRPC ストリーミング](/guides/streaming/) を使い分けてください。
:::

## インストール

:::caution[Node.js バージョンについて]
**mixi2-js v1.5.0 より、Node.js v20.19.0 未満はサポートされなくなりました。** Node.js v18 系では動作しません。Node.js v20.19.0 以上をご使用ください。
:::

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install mixi2-js
    ```
  </TabItem>
  <TabItem label="JSR">
    ```bash
    npx jsr add @otoneko1102/mixi2-js
    ```
  </TabItem>
</Tabs>

ESM・CommonJS の両方に対応しています。TypeScript の型定義 (`.d.ts`) も同梱されています。

:::note
JSR 経由でインストールした場合、インポートパスは `'mixi2-js'` ではなく `'@otoneko1102/mixi2-js'` になります。
以降のコード例はすべて npm 版のパスで記載しています。JSR 版をお使いの場合は適宜読み替えてください。
:::

## モジュール一覧

| モジュール            | 説明                                                                                |
| --------------------- | ----------------------------------------------------------------------------------- |
| `OAuth2Authenticator` | OAuth2 Client Credentials 認証（トークン自動キャッシュ・有効期限 1 分前に自動更新） |
| `Client`              | gRPC API クライアント (公式 API の全 15 RPC に対応)                                 |
| `WebhookServer`       | HTTP Webhook サーバー（Ed25519 署名検証・Ping 自動応答）                            |
| `StreamWatcher`       | gRPC ストリーミング（指数バックオフによる自動再接続）                               |

## 認証

すべての API 操作に OAuth2 認証が必要です。

<Tabs>
  <TabItem label="npm">
    ```typescript
    // ESM
    import { OAuth2Authenticator } from 'mixi2-js';
    // CJS
    const { OAuth2Authenticator } = require('mixi2-js');
    ```
  </TabItem>
  <TabItem label="JSR">
    ```typescript
    import { OAuth2Authenticator } from '@otoneko1102/mixi2-js';
    ```
  </TabItem>
</Tabs>

```typescript
const authenticator = new OAuth2Authenticator({
  clientId: process.env.CLIENT_ID!,
  clientSecret: process.env.CLIENT_SECRET!,
  tokenUrl: process.env.TOKEN_URL!,
});

// アクセストークンを取得（キャッシュ済みの場合は即座に返却）
const token = await authenticator.getAccessToken();
```

### OAuth2Authenticator

OAuth2 Client Credentials フローによる認証を管理します。

```typescript
new OAuth2Authenticator(options: AuthenticatorOptions)
```

| プロパティ     | 型       | 説明                            |
| -------------- | -------- | ------------------------------- |
| `clientId`     | `string` | OAuth2 クライアント ID          |
| `clientSecret` | `string` | OAuth2 クライアントシークレット |
| `tokenUrl`     | `string` | トークンエンドポイント URL      |

| メソッド           | 戻り値            | 説明                                                                    |
| ------------------ | ----------------- | ----------------------------------------------------------------------- |
| `getAccessToken()` | `Promise<string>` | アクセストークンを取得。有効期限の 1 分前までキャッシュし、自動更新する |

`Authenticator` インターフェースを実装しているため、カスタム認証を独自に実装することも可能です。

:::tip
認証情報は環境変数またはシークレット管理システムから読み込んでください。ソースコードへのハードコードは避けてください。
:::

> 詳細は [公式ドキュメント](https://developer.mixi.social/docs) を参照してください。
